Projektplakat

Das Plakat fasst die Projektarbeit auf einer Seite im Format A1 hoch (594 × 841 mm) zusammen: Ziele, Plattform, Systemarchitektur, die Navigation ohne GPS, der Nutzlast-Abwurf, das Sicherheitskonzept und der Projektstand.

Druck-PDF öffnen HTML-Quelle

#Quelle und Druck

Das Plakat ist eine einzelne HTML-Datei, docs/poster/plakat.html, ohne externe Abhängigkeiten. Alle Maße stehen in Millimetern, das Seitenformat setzt eine @page-Regel. Das PDF ist daraus erzeugt und wird mitversioniert, damit niemand für einen Druck erst eine Toolchain aufsetzen muss.

PDF neu erzeugen:

"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=docs/poster/plakat.pdf \
  "file://$PWD/docs/poster/plakat.html"

Alternativ im Browser öffnen und drucken — Papierformat A1, Ränder keine, Option Hintergrundgrafiken aktiviert, Skalierung 100 %.
